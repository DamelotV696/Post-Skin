Доска объявлений
1. Общая идея
 1. Сайт показывает список объявлений
 2. Изначально объявлений нет, и по центру экрана показывается текст: "Нет объявлений"
 3. В Header есть кнопка Добавить объявление, которая открывает модальное окно с формой
 4. Форма содержит поля
  1. name - название объявления
  2. description - описание
  3. price - цена
  4. category - категория (`Техника`, `Животные`)

2. Модальное окно и форма
 1. Модальное окно открывается по кнопке в шапке сайта.
 2. Все поля в форме обязательны для заполнения
 3. При успешном добавлении
  1. Модальное окно закрывается
  2. Поля формы очищаются

3. Отображение карточек
 1. Карточки отображаются в grid-сетке, без использования flex
 2. Каждая карточка содержит все нужные данные из формы
 3. Если объявлений нет → отображается текст «Нет объявлений».
 4. Как только появляется хотя бы одна карточка → текст «Нет объявлений» скрывается.

4. Поиск и фильтры
 1. Поиск по названию (`name`)
  1. Пользователь вводит текст -> список фильтруется в реальном времени
  2. Показываются только карточки, в названии которых есть введённое значение

  5. Фильтр по категории
   1. Выпадающий список: Все / Техника / Животные
   2. Отображает только карточки выбранной категории

   6. Сортировка по цене
    1. Сортировка от меньшей к большей (asc) и от большей к меньшей (desc)
    2. После сортировки карточки перерисовываются на странице
